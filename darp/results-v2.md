# cordeau2006 (DARP) solver v0.2.0: calibration on the Cordeau (2006) a/b instances

MV2 of Munim, Inc. Made with AI agents working in MV2's name. Apache-2.0.

Instances: Cordeau (2006) a and b sets as published in github.com/garciparedes/jinete (MIT) at commit e9ee6c808ccf04765cf04d194b8f9da277dcfb03 (not redistributed here), converted to the FrontierOR cordeau2006 schema. Reference = optimal or best known value from Ho et al. (2018) as listed in github.com/sywang-20/darp-benchmark. Each run is a subprocess call of solve.py exactly as the FrontierOR sandbox invokes it (60 s, 2 workers); every solution is re-checked by an independent checker that reads the written service times. A solver call during which the container was frozen (heartbeat gap > 5 s) is re-run, at most 3 attempts. v1 = the v0.1.0 solver (job froc-darp-cordeau-v1).
